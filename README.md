# Brimholt

An original Godot tile-world prototype for up to **twelve LAN players**, including a
playing host. It uses native ENet, server-authoritative grid movement, collision,
smooth visual interpolation, a flat backpack with ground items, layered visible
equipment, and a 256×256 world with ferry travel. The map and all sprites are original;
the pixel art is generated by `tools/generators/make_sprites.py` and the world is painted in Godot's
TileMap editor. Brimholt is a working name;
trademark/name availability has not been verified.

## Setup and LAN play

Requires **Godot 4.5+**; development checks use **4.5.1**. Open `project.godot` in
Godot and press **F5**, or run from this folder:

```sh
godot --path .
```

Replace `godot` with your executable path if it is not on PATH. There is no Node
server, external service, API key, or bundled engine dependency.

After a fresh checkout (or new sprite sheets), import the assets once before running
from the command line: open the project in the Godot editor, or run `make import`
(`godot --headless --path . --editor --quit`). Otherwise sprites fail to load.

Without `--host` or `--join` (for example when you press F5 in the editor), the game opens
on a start menu over Cinder Crossing: pick a vocation and click **Host a game** in one
instance. In another instance, enter the host's LAN IPv4 address and click **Join**. Use `127.0.0.1` only for two instances on the same
computer. All computers must use the same project files. Allow inbound **UDP
1234** through the host firewall; ENet does not use TCP/WebSockets.

```sh
# Playing host
godot --path . -- --host

# Client on the same computer; replace the IP for another LAN computer
godot --path . -- --join=127.0.0.1

# Optional dedicated host: no host character, up to twelve clients
godot --headless --path . -- --headless-server
```

For an alternative UDP port, add `--port=1235` after `--` on every instance.
The world resets when the host stops; there is no persistence. This is a
**trusted-LAN prototype**, not an Internet-ready service. Do not expose its port
to the public Internet.

## Controls

These are the default keys; every key can be changed (see below).

| Control | Action |
| --- | --- |
| WASD / arrows | Move one cardinal tile; hold to repeat |
| Left-click a creature | Lock it as your target (click again to release) |
| Space | Target the nearest monster |
| 1–9 | Cast the spell in action bar slot 1–9 (filled with your vocation's spells) |
| Drag an item | Move it between backpack slots, equipment slots, and nearby tiles |
| Right-click item | Equip from the backpack, or unequip into the backpack |
| Right-click tile / G | Pick up the top item on a tile (G: your tile, else the one you face) |
| Hover an item | Show its slot and stats |
| Right-click a person | Open their menu (ferrymen: **Travel**) |
| Right-click / click a bar slot | Choose its spell / cast it |
| M | Open or close the world map |
| Esc | Close menus, or release your target (cannot be rebound) |
| Leave / close window | Disconnect; leaving the host ends the session |

Walls, water, trees, ferrymen, and players block movement. A gold ring marks your
character; the minimap in the side panel follows you.

More: [gameplay](docs/gameplay.md) (action bar, combat, parties, loot, death and skulls,
the world, inventory, stats).

## Development

Common tasks run through `make` (macOS and Linux; set `GODOT=/path/to/godot` if Godot is
not on PATH). `make` alone lists them.

```sh
make import        # after a fresh clone, new sprites, or moving files
make run           # start menu;  make host / make join ADDR=192.168.1.20 / make server
make test          # unit rules + real-ENet scenarios (about 1 minute)
make check         # import + test + offscreen visual checks
make playtest      # two-bot full-game playthrough with an HTML report (about 5 minutes)
make sprites       # regenerate assets/sprites
```

## Scope and reference licensing

Blessings, yellow and black skulls, loot protection, the final raid boss, nested containers, trading, shops, quests, procedural caves, floors, NPCs other
than the menu-driven ferrymen, persistence, and authentication are outside this prototype.

[The Forgotten Server](https://github.com/otland/forgottenserver) (GPL-2.0) and
[OTClient Redemption](https://github.com/mehah/otclient) (MIT) are useful references
for high-level container/item concepts and inventory-event/UI separation, not
Godot/ENet dependencies. No third-party code or assets are imported here. Do not
copy or translate GPL code into this project without a licensing decision.
MIT reuse requires checking the specific files/dependencies and retaining their
copyright/license notices. Neither engine's source license grants rights to
proprietary Tibia sprites, maps, or client data.
